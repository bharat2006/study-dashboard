One-time cloud setup needed
This dashboard needs a free Firebase project to sync your data across your PC and phone.

1. Go to console.firebase.google.com → Create a project (free)
2. Build → Authentication → Get started → enable Email/Password
3. Build → Firestore Database → Create database (production mode, any region)
4. Firestore → Rules tab → paste the rule below → Publish
5. Project settings → your apps → Web app (</>) → copy the firebaseConfig object
6. Paste it into the firebaseConfig variable near the top of this file's <script> section, then reload this page.
